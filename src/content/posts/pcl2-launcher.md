2026年10月20日，PCL2 更新到 2.99.0.0。

更新日志的第一条很短：为遵守相关法律法规，不再提供游戏本体下载功能。几天后，2.99.0.1 把下载相关入口也隐藏了。作者龙腾猫跃在说明里写，这不是暂时下架。

对不玩 Minecraft 的人来说，这只是一行版本说明。对国内一批 Java 版玩家来说，那个用了很多年的“下载”标签页，没了。

PCL 的全称是 Plain Craft Launcher。它是一个 Windows 上的第三方启动器，免费、开源，主要由龙腾猫跃一个人维护。它最早被记住，是因为轻：一个 exe，双击就能跑，不用安装，没有捆绑，没有弹窗广告。它被记住的第二个原因，是下载。

在很长一段时间里，国内玩家打开 PCL2 的流程是固定的：下载一个 exe，双击，等它自己更新，然后在下载页选一个版本。Java 不用自己装，Forge、Fabric、NeoForge 不用自己找，模组依赖它会提示，整合包可以一键导入，崩溃了还有分析。它把“玩 Minecraft”之前那一堆麻烦事，收进了一个窗口。

这些东西今天听起来像基础设施。但在当时，它们不是。官方启动器需要微软账户和正版授权，网络也不总是顺畅。第三方启动器填补了这段路。PCL2 不是唯一一个，却是最像“一个 exe 解决所有问题”的那个。

2026年10月，社区里开始流传一个说法：有未成年人在某个私服充值，家长举报了私服，也顺手举报了启动器。这个说法没有被官方证实。能确认的是结果：PCL2、HMCL、ZL 等国内第三方启动器相继关闭了游戏本体下载通道；HMCL 在 GitHub 上对国内地区的资源获取加了限制。MineBBS 的信息显示，这次调整不是网易、Mojang 或微软主动干预，而是举报带来的连锁反应。

龙腾猫跃在更新说明里提到，GitHub 账号被封禁，CDN 持续遭到攻击，部分平台关停，更新日志只能在夹缝里发布。一个个人开发者，面对的是账号、带宽、分发渠道同时出问题。他没有太多缓冲。

PCL2 没有消失。它仍然可以启动你已经装好的游戏，仍然能管理版本和模组，仍然能导入本地整合包。消失的是那个把游戏本体、Java、模组和整合包一起搬进来的入口。

社区版 PCL CE 还在更新。2026年10月20日，PCL CE 2.15.1 发了30项改动，包括内存初始/最大堆分别设置、模组内嵌依赖检测、MultiMC 整合包支持完善、下载器重构。代码没有死，维护也没有完全停下。

但一个时代确实退场了：启动器曾经是内容分发渠道，现在退回成启动器。

我们这一代玩家评价一个启动器的标准，曾经是“下载快不快”。以后可能要改成“能不能把我已经有的东西启动好”。这个变化听起来很小，其实很大。前者考验的是分发能力，后者考验的是兼容、性能和稳定性。前者可以靠一个按钮完成，后者要靠长期维护。

更麻烦的是，一个由个人维护的免费工具，曾经承担了接近基础设施的角色。基础设施一旦被举报、被封禁、被攻击，个人开发者没有多少缓冲。PCL2 的下载按钮消失，不是一个软件的失败。它更像一条边界被重新画了一遍：哪些事情可以由一个免费工具替官方完成，哪些不能。

下次打开 PCL2，你还会看到版本列表、模组管理和启动按钮。只是那个曾经能把整个 MC 世界搬进电脑的标签页，不在了。
