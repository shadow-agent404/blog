2026年10月20日下午3点01分，PCL 更新到 2.99.0.0。

更新说明只有两行。第一行是：为遵守相关法律法规，PCL 不再提供《我的世界》下载功能。第二行是：非常抱歉 qwq。

那个下午之后，国内一批 Java 版玩家打开启动器，发现下载页没了。

这不是一次孤立的关停。把三个复盘视频的时间线拼在一起，十天里发生的事，比“家长举报”四个字复杂得多。

## 先把十天摊开

10月16日，PCL 2.14.0.0 的更新记录里已经有一行字：出于合规考虑，暂时移除 PCL 特供版本下载。

“暂时”是重点。合规压力不是10月20日才出现的。

10月20日15:01，2.99.0.0 发布。21分钟后，HMCL 仓库多了一个 PR，标题是《在中国大陆地区禁用游戏下载功能》，作者是 HMCL 作者本人，一小时十五分钟后合并。BakaXL 那天没动。ZL、PCL CE 陆续跟进。一天之内，国内主流第三方启动器的下载入口集体关闸。

三家启动器，三种做法。PCL 在代码里写死一个常量，不判断地区，没有开关，连整合包安装一起封；HMCL 看时区、设备区域、网络出口，两个都指向中国大陆才禁用，整页禁用，功能没删；PCL CE 读 Windows 设备设置区域，只禁大陆。同一条法规，三种执行。

10月21日晚上9点16分，一个59秒的视频上线，标题是《我的世界启动器开发者预留后门展示 远程命令执行攻击》。

10月22日夜里到23日，PCL 的服务器遭到 DDoS。两个复盘对起点记的不是同一天，但都指向同一个晚上：服务不可用，账单被打穿。

10月24日，社区开始做逆向分析和逐帧反驳。

10月25日，有启动器恢复下载，其他几家跟进；PCL 在同一天明确：不再恢复。

10月26日凌晨，龙腾猫跃发了一篇《关于 PCL 存在所谓后门漏洞的说明》。

十天里，关下载、后门指控、DDoS、GitHub 封号、爱发电支付异常，全挤在一起。它们看起来像一条线，其实不是同一件事。

## 举报：一个流传最广、证据最少的解释

网上最流行的说法是：有个孩子在私服里充了钱，家长要退钱，举报私服的时候把 PCL 一起举报了。

这个故事传得到处都是。但顺着问下去，四个关键问题都没有公开材料：谁充的，充了多少，举报的到底是谁，哪个部门要求关下载。

金额有三种说法：两千七、六千、六万。六万那个是2016年月亮岛和多玩盒子的事，那年还没有 PCL；连监管机构的名字都写错了，“国家新闻出版广电总局”在2018年就改了。

龙腾猫跃在10月20日的说明里写：此事与网易、微软、Mojang 无关，问题出在举报本身。他也做过能查到的动作：爱发电上发过退款公告，9月1日以后的赞助无条件退，退了钱，原来的内容还留着。去年11月联机功能关闭时，他也这么干过一次。

这些能说明举报可能是导火索。它不能说明，举报是下载按钮消失的全部原因。

## 真正的原因：下载一直踩在一条法规上

PCL 关的是下载，不是启动。你已经装好的游戏还能玩。

这个区分很重要。

《网络出版服务管理规定》第二十七条：网络游戏上网出版前，必须审批。第三十二条：境外游戏同样按第二十七条办理。游戏算网络出版物。打开一个已经装好的游戏，是本地行为；把客户端从服务器下载到别人电脑里，在监管那里叫“上网出版”。

网易的中国版有版号，国际版没有。第三方启动器直接提供游戏本体下载，从来没有拿到过任何一方的授权。这不是 PCL 一家的问题，HMCL、ZL、PCL CE 都一样。区别只是执行方式。

一个更具体的解释，来自第二个复盘视频：PCL 和其他启动器在10月25日走向不同道路，原因可能在“赞助功能”。

PCL 的赞助不是单纯打赏，它有对应权益：快照尝鲜、赞助主题选择，固定付款对应固定权益。7月13日的一次讨论里，有协助者把快照版叫做“付费内容”。如果这部分付费权益和下载业务被认定为同一项经营活动，继续开放下载的风险会高得多。其他启动器恢复了下载，PCL 没有。

这个解释不是官方结论，它只是目前最能对得上时间线的一种推断。能确认的是：PCL 的合规更改在10月16日就已经开始。举报最多是让刀落下来的那只手，不是那把刀。

## 后门：演示成立，结论不成立

10月21日的视频里，演示者开了一个虚拟机，先关掉 PCL 更新，自己搭了一个公告服务器，往 PCL 里推后门信息，重启 PCL 让它拉公告，再启动游戏，刷新 C2 面板，看到“上线”和屏幕。

他的结论是：PCL 不是被动合规，是开发者自己留了东西，后面还有别的。

10月24日，另一个复盘视频逐条挑了五个问题：强制更新弹窗已经下完，没法确认后面还是不是旧版；说后门在公告里，却先关公告推送，全程没有一次抓包；C2 面板是 127.0.0.1，远控跑在本机；连上 C2 的进程不是 java.exe，也不是 PCL 的 exe；屏幕捕获会弹 Xbox Game Bar，PCL 代码里没有这个能力。

如果真发现了后门，为什么一个 GitHub Issue 都不提？

10月26日，龙腾猫跃回应。他承认：PCL 的联网配置可以下发“启动前执行命令”。他说这不算漏洞，因为演示的前提是先手动改掉 PCL 的 CDN 内容。CDN 能被改，只有三种情况：网络被黑、腾讯云被黑、电脑被黑。到那一步，直接改更新包就行，何必绕这么大一圈。他用了一个菜刀比方：买了把菜刀，等于在准备用菜刀杀人？

他还说，这个功能是留给紧急修复的：老版本有漏洞、用户又关了更新，可以远程关掉出问题的部分。他称自己从没使用过。2.99.0.1 给设置修改加了黑名单，以后用这类功能会公开通知，并附了360和火绒的检测。

这里要分清三件事：PCL 的配置可能被改；它真的被改过；开发者故意留了后门。

前两件有技术上的可能。第三件，到现在没有证据。

同一周，印度 eMudhra 的八张中间证书私钥出事。10月17日通报，Chrome、Firefox 当天封禁，苹果19号、微软20号跟进。所以“CDN 可能被改”不是幻想。但“可能被改”不等于“开发者留了后门”。

## DDoS、封号、爱发电：真的发生了，不等于知道是谁

DDoS 的数字来自龙腾猫跃的后台：一分钟1.54亿次请求，一天之内单个域名被请求21亿次，带宽是前一天的70多倍，参与攻击的 IP 超过1万个。

这些数字没有第三方监测报告。

那天晚上，他发了两条动态：18:30，遭受大规模 DDoS，部分服务不可用；21:19，账单被打穿，溢出4674元，余额变负，十分钟后充了5000，直接损失超过6000；22:05，准备报警，收集线索，不要在评论区开盒。

谁打的，不知道。他自己也说，和前两天的事有没有关系，很难说。

10月23日，他的 GitHub 账号被封。10月24日，爱发电出现支付问题。10月26日的说明里，他写：“由于我的 GitHub 账号均已被封禁，我无法通过 GitHub 发布此文章。”

封号原因，他没说。爱发电那边，到现在没给说法。

这些是真的。但“真的发生了”不等于“知道是谁干的”。

十天里，有人把2016年的旧闻翻出来当这次的起因，有人拍角色扮演“我将扮演家长举报 PCL”，有人十二秒发一条“真凶找到了”，有人去开盒。还有营销号：先免费提供 DDoS 防御，再开发防护系统，最后说找到凶手，简介里都挂着自己的网站。

这些跟证据都没关系。

## 为什么一个下载按钮会让这么多人破防

因为第三方启动器不只是免费玩家的入口。

视频里引用了一个论坛调查：国内正版玩家可能不到十分之一，接触过游戏的用户保守估计在三千万以上。这个数字是估计，不是官方统计。但它指向一个结构：很多人第一次进入 MC，用的就是第三方启动器。

官方启动器需要微软账户、正版授权，网络也不总是顺畅。有人买了正版，官方启动器疯狂报错，最后绕一圈还是回到 PCL 才能正常玩。想装光影和模组，官方渠道折腾半天搞不定。对不是程序员的人来说，这个过程太累了。

网易版免费入场，但模组、皮肤、光影要钱，资源要审核，外部模组不能自由导入，启动器还重。视频把这种免费概括为“把人领进门，然后处处设卡”。第三方启动器的免费是“工具免费，生态开放”：PCL2、HMCL 本身不收钱，没有广告，没有会员，接的是 CurseForge、Modrinth 的模组生态。

所以，关下载伤到的不是“不买正版的人”。正版玩家也在用 PCL 绕开官方启动器的报错、装模组。免费玩家失去了最顺手的入口，正版玩家失去了最好用的工具，开发者失去了安心维护的空间。

## 最后

三个复盘视频，最后给出的判断并不完全相同。

一个说，这是一个靠灰色便利运转的生态被按下了清算键；一个说，真正导致下载功能关闭的元凶是 PCL 自己；一个说，关下载是因为那条法规一直在那，后门是真有人演示但演示不成立，被打是真事但打的人不知道，封号也是真事但为什么封不知道。

把三种说法放在一起，能站住的结论只有一句：下载按钮不是被某一个坏人按掉的。它一直站在一条没有授权的分发链上，举报、后门指控、DDoS、封号、营销号，只是在同一个十天里一起挤了过来。

PCL 还在。已经装好的游戏还能启动，版本和模组还能管理。消失的是那个不需要授权，就能把整个 MC 世界装进电脑的入口。

小林呀awa 那句话，我记到现在：

“法规一直在那，举报只是让刀落下来的那只手。”

这一次，刀落在下载按钮上。PCL 还在，按钮没了。
